## How to Run

### 运行方式

由于使用 ES Modules，需要通过本地服务器运行：

```bash
# 方式1: 使用 npx serve
npx serve .
# 访问 http://localhost:3000

# 方式2: 使用 Python
python -m http.server 8000
# 访问 http://localhost:8000

# 方式3: 使用 VS Code Live Server 插件
# 右键 index.html -> Open with Live Server
```

### 运行要求

- 现代浏览器（Chrome、Firefox、Edge、Safari）
- 网络连接（用于加载 Three.js 3D 引擎）

纯前端静态页面，无需后端服务。Three.js 通过 CDN (unpkg.com) 加载。

## 题目内容

我是一名高中地理老师，需要做一个雅丹地貌形成过程的实验模拟平台。具体要求：

1. 创建出地壳下沉运动形成湖泊的动态过程。湖泊底部湖相沉积岩形成的动态过程。气候暖干使得湖泊干涸，湖床裸露的过程。湖床裸露沉积岩层干裂，风沿裂隙侵蚀，侵蚀宽度和深度增大的过程，最终坚硬部分未被侵蚀形成垄脊，侵蚀部分形成沟槽。

2. 地壳下沉、湖泊形成、湖相沉积岩沉积、气候暖干、湖床裸露、风力侵蚀过程均可以调整其参数变化。

3. 这些过程还可以转动角度观察雅丹地貌的形成过程。

4. 全屏播放，左侧为控制面板及实验讲解，右侧为实验界面，布局上分为左右两部分。

5. 整体画风呈现科技风。

6. 所有代码输出为一个HTML文件。

## 项目介绍

### 雅丹地貌形成过程模拟实验平台

基于 Three.js 的 3D 交互式地理教学模拟平台，使用 GPU 着色器实现地形动态变形，完整演示雅丹地貌从地壳运动到风蚀成型的全过程。

### 五阶段模拟

1. **初始平原** - 平坦地表，古老基岩
2. **地壳下沉** - 构造运动形成断陷盆地
3. **湖泊沉积** - 湖相沉积岩逐层形成
4. **气候干裂** - 湖泊干涸，湖床龟裂
5. **风力侵蚀** - 风沿裂隙侵蚀，垄脊沟槽形成

### 可调参数

| 参数       | 说明               | 影响阶段 |
| ---------- | ------------------ | -------- |
| 下沉深度   | 地壳下沉的深度     | 沉降阶段 |
| 水位高度   | 湖泊水位           | 沉积阶段 |
| 沉积厚度   | 湖相沉积岩厚度     | 沉积阶段 |
| 干旱化速率 | 气候变暖变干的速度 | 干裂阶段 |
| 风力强度   | 风蚀作用强度       | 侵蚀阶段 |
| 垄脊密度   | 雅丹垄脊的密集程度 | 侵蚀阶段 |

### 交互功能

- 拖动进度条或自动播放
- 点击阶段指示器跳转
- OrbitControls 自由旋转缩放
- 预设视角切换（俯视/正面/侧面/自由）
- 自动旋转观察
- 按钮悬停显示功能提示
